Sistema de Gerenciamento de Tarefas

Projeto acadêmico desenvolvido para aplicação dos conceitos de Desenvolvimento Web.

📌 Sobre o Projeto

O Sistema de Gerenciamento de Tarefas tem como objetivo auxiliar usuários na organização de atividades pessoais e profissionais, permitindo cadastrar, visualizar, concluir e excluir tarefas.

A aplicação foi desenvolvida utilizando arquitetura simples, integração com banco de dados e interface responsiva.

🚀 Funcionalidades

  • Cadastro de tarefas
  • Descrição das atividades
  • Listagem das tarefas cadastradas
  • Alteração do status para concluída
  • Exclusão de tarefas
  • Persistência dos dados em banco

🛠 Tecnologias utilizadas

  • Python
  • Framework Flask
  • Flask SQLAlchemy
  • Banco SQLite
  • HTML5
  • CSS / Bootstrap

🎯 Objetivo Acadêmico

Este projeto tem como finalidade demonstrar conhecimentos em programação web, criação de aplicações utilizando Python, manipulação de banco de dados e desenvolvimento de interfaces.
